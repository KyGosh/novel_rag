# 消融表 v1：固定流程 RAG 的检索链路（asoiaf_v0 dev，设置 A：检索范围为卷一）

- 评测集 asoiaf_v0 的 dev 划分，60 题（四类各 15 题）；相关性 = 证据区间与 chunk 重叠 ≥ min(区间 50%, 50 字)。
- R@K 按证据统计（只看前 20 名）；cov@4000 = 从前 40 名命中（该行开了 small-to-big 时先扩展）按名次贪心装进 4000 token 后覆盖的证据比例。
- 不同分块大小、扩展前后之间比较以 cov@4000 为准（R@K 会随块变大而虚高）。
- 每行只改一处；对照列是该行做配对比较的基准。除'+small-to-big ±1'外各行都不扩展。
- 选定基线：RRF(向量+BM25-IK) k=60 + rerank 候选 40，不扩展，chunk 0c94b7e4；test 只跑这一次（p2_baseline_test）。
- 设置 B（全五卷不过滤）的假漏检抽查：排在金标前的范围外命中取 20 条，能回答 1、可能 1、不能 18，假漏检约 5%–10%，掉分主要是真实噪声；20 条中 6 条是其他卷的附录名表。
- 延迟在 RTX 4060 Ti 独占 GPU 时测得；rerank 约 16 ms / 候选。
- 方括号为 95% bootstrap 置信区间（按题重采样 2000 次）；差值列是相对于对照行的配对差值，↑/↓ 表示区间不含 0。
