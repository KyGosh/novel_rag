# 消融表 v2：P3 检索价值验证——摘要定位、图谱第三路、人名词典（asoiaf_v0 dev，设置 A：检索范围为卷一）

- 评测集 asoiaf_v0 的 dev 划分，60 题（四类各 15 题）；相关性判定与 v1 相同。按题型的数字每格只有 15 题，结论以配对差值及其置信区间为准。
- 基线 = P2 选定的固定流程 RAG：RRF(向量 + BM25-IK) k=60 + rerank 候选 40，不扩展，chunk 0c94b7e4。p3a_baseline_es1 在当前 commit 上复现了 P2 的 p2a_rr40，逐题一致。
- 摘要定位：章节摘要（d8139169，349 章）建 ES + Milvus 索引，先取前 N 章。route = 章内 BM25 + 向量结果作为第三路接入 RRF；restrict = 整条链路只在这 N 章内检索。
- 图谱第三路：问题中最长匹配链接实体（只用阅读进度内可见的名字），取实体间直接关系 / ≤3 跳路径的证据 chunk（tier 1），tier 3 再加各实体主要关系与高频提及 chunk；排成一个列表接入 RRF，再统一 rerank。图谱版本 d9c84c78。
- 人名词典：从图谱导出 5790 个实体名、别名及名字片段写入 IK 扩展词典，重启 ES 后新建 es2 索引。IK 词典是全局的，回灌后 es1 的查询端分词也变了，所以 es1 一侧的数字一律取回灌前的运行（p2a_bm25_ik、p3a_baseline_es1）。
- 章节定位诊断（eval/results/*_p3a_chapter_locate）：金标证据章节的召回@N，摘要检索 vs chunk 检索前 40 名所在章节。总体 @1 0.397 vs 0.456、@5 0.697 vs 0.792；人物关系 @1 0.567 vs 0.333、跨章节 @1 0.256 vs 0.222——摘要更擅长把最相关的一章排到第一，但纵深不如 chunk 检索。
- 检索延迟在 RTX 4060 Ti 上测得；图谱第三路的 Neo4j 查询在本机容器中执行。
- 方括号为 95% bootstrap 置信区间（按题重采样 2000 次）；差值列是相对于对照行的配对差值，↑/↓ 表示区间不含 0。
